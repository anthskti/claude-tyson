# Source provenance and third-party components

This notice is adapted from the source harness. The MVP copies only its six core Python modules and an optional config profile; their hashes are in `SNAPSHOT.json`. The transport, contract adapter, browser provider and module tests were added for this MVP. No source files, meshes, textures or scripts from Punching Face or BitBoxer were copied into this kit. Synthetic landmarks are hand-authored software fixtures and contain no user video.

- **MediaPipe:** dependency source is under [Apache-2.0](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE). This kit uses the Tasks APIs. Official model assets download separately; their exact URLs and SHA-256 values are recorded in `models/manifest.json`. The [BlazePose GHUM model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf) identifies Apache-2.0 for that model family. Consult the [Hand Landmarker model/card links](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker#models) for hand-asset notices before redistributing a bundle.
- **OpenCV:** see the [OpenCV license](https://github.com/opencv/opencv/blob/4.11.0/LICENSE) and [Python wheel repository](https://github.com/opencv/opencv-python) for its license and bundled-library notices. The contrib distribution supplies `cv2`; no OpenCV source is copied here.
- **Other Python packages:** their distribution metadata and licenses remain in the installed packages. Direct dependency versions are pinned in `pyproject.toml`; this is not a complete transitive dependency freeze and does not replace those notices.
- **Reference projects:** at inspected commits, neither repository exposed a root-wide reuse license through its tree/API. They are research references only. Punching Face's [boxing glove asset notice](https://github.com/akashngb/punching-face/blob/3cffc249888e652774d8edd1149f13858f740a2a/boxing_glove/license.txt) specifically credits Incg5764 under CC-BY-4.0; this grant is asset-specific. That model is not included here.
- **Validation inputs:** the source harness used public Google still-image assets in its earlier checks. This MVP's native integration check used a local user recording, not bundled here. Only a synthetic sample packet and a synthetic browser screenshot are distributed.

Before the hackathon, identify this kit as pre-event research/boilerplate and check the applicable rules. This document does not assert that the event permits prewritten code, or grant new rights over any third-party material.
