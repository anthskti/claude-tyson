# MediaPipe assets

Moved unchanged from the deprecated cv-mvp package. Exact official download URLs, hashes and sizes are in manifest.json. scripts/cv-assets.ts verifies the hashes before publishing the unchanged browser URLs. The demo native runtime uses only pose_landmarker_lite.task.

MediaPipe dependency source: https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE (Apache-2.0). Pose model card: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf. Hand model/card links: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker#models. Retain the relevant package and model notices when distributing.
